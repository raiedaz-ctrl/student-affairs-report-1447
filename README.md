# التقرير التفاعلي لبرامج وأنشطة عمادة شؤون الطلاب 1447هـ

موقع ثابت تفاعلي مبني من ملف:


## التشغيل المحلي

افتح هذا المجلد ثم شغّل:

```powershell
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع كل ملفات هذا المجلد إلى المستودع.
3. من إعدادات المستودع اختر Pages.
4. اختر النشر من الفرع الرئيسي `main` ومن الجذر `/`.

## الملفات المهمة

- `index.html`: بنية الصفحة والشرائح.
- `styles.css`: التصميم والحركات والاستجابة للجوال.
- `app.js`: التنقل، العدادات، المخططات، البحث، والتصفية.
- `data.js`: بيانات البرامج والأنشطة المولدة من ملف Excel.
- `vendor`: مكتبات الرسم المحلية.

## الشعار

لإظهار شعار الجامعة داخل التقرير، ضع ملف الشعار في المسار:

```text
assets/kau-logo.png
```

وفي حال لم يوجد الملف، يظهر بديل نصي مرتب بدل ظهور صورة مكسورة.
